# Expedey

Expedey is an agentic AI engineering company with offices in Houston, Texas and Karachi, Pakistan. We build production AI systems: AI agents, the harnesses that make them reliable, multi-agent workflows and RAG, plus the custom software they run in.

### What we build

- **[AI agents and harness engineering](https://www.expedey.com/services/agentic-ai-development/)**: agents with typed tools, permissions, human approval for risky actions, evaluations and tracing
- **[Document processing agents](https://www.expedey.com/services/ai-document-processing-agents/)**: read RFPs, contracts and scanned PDFs, extract requirements and check them against your rules
- **[Proposal and RFP automation](https://www.expedey.com/services/ai-proposal-automation/)**: requirement extraction, gap analysis and drafts built on your own past work
- **[Customer support agents](https://www.expedey.com/services/ai-customer-support-agents/)**: answers from your help center, actions within policy, hand-off to a person
- Web applications, mobile apps and MVPs

### Open source

**[agent-harness-template](https://github.com/Expedey/agent-harness-template)**: a small, production-minded harness for LLM agents in Python. Agent loop with budgets, typed tools, human approval, context management, retries and fallback models, tracing and evaluations. Tests run without an API key.
